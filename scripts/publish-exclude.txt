# Paths excluded from the public open-core distribution.
#
# Consumed by scripts/build-public-tree.sh as `grep -vEf` patterns, matched
# against repo-relative paths. One extended-regex per line; '#' comments and
# blank lines are stripped by the script.
#
# NOTE: a blank pattern line matches EVERY path. The script strips them for
# exactly that reason — an accidental empty line here would otherwise silently
# produce an empty tree.
#
# Everything NOT listed here ships. Adding a path is a deliberate act; justify it
# in a comment so the next person knows whether it still applies.

# ─── Operator-local agent configuration ──────────────────────────────────────
# .claude/settings.json is rewritten by whatever agent tooling the operator runs
# (locally, a security daemon toggles `hooks`/`disableAllHooks` in it). That makes

# re-infected copy would carry absolute paths into the operator's home directory.
# It is editor/agent config, not product code; contributors generate their own.
^\.claude/settings\.json$
